# 📂 AI File Organizer

> *Because my Downloads folder deserves better.*

---

## 🧹 The Problem

You download one file.

Then another.

Then another...

A few weeks later your folder looks like this:

```text
Resume.pdf
photo.png
movie.mp4
song.mp3
python.py
setup.exe
notes.txt
vscode.zip
cat.jpg
```

Absolute chaos.

So instead of cleaning it myself...

I'm making Python do it. 😌

---

## 🚀 The Mission

Build a program that looks at a folder, figures out what every file is, creates the right folders if they don't exist, and neatly puts everything where it belongs.

From this...

```text
Downloads/
```

to this...

```text
Downloads/

📁 Documents
📁 Images
📁 Videos
📁 Music
📁 Code
📁 Programs
📁 Archives
```

One click.

Everything sorted.

---
